# Changelog

## Unreleased

### Added
- **GPU pressure / TDR reduction on shared-GPU handhelds** - LiftOff now eases GPU/VRAM contention that could trigger a driver reset (`DXGI_ERROR_DEVICE_RESET`/TDR) on devices like the ROG Ally. On game launch, the WebView2 window briefly hides (~400 ms after the launch handoff) to release its D3D compositor resources before the game initializes its own device, then restores when the launch overlay is dismissed or focus returns unexpectedly (e.g. a crashed game). A new default-on `hide_on_launch` setting gates this with no UI toggle yet. WebView2 also runs with GPU-friendly Chromium flags (`--disable-gpu-memory-buffer-video-frames --enable-zero-copy --num-raster-threads=2`) to lower video-frame VRAM use and raster contention. Hardware acceleration and `backdrop-filter` remain enabled.
- **Steam store info in Game Details** - Game Details now shows Steam store page info when available, with the short description, a numbered trailer/screenshot media row, and the existing action grid. After controls are revealed, a compact Details / Manage tab strip with LB/RB badges appears beside Play; LB/RB switches tabs, media opens fullscreen with B returning one level to the modal, and non-Steam games, offline/error cases, or disabled store metadata keep the old no-tab action grid.
- **Store metadata layer with Steam provider** - LiftOff now has backend-only, on-demand store metadata plumbing for Steam games, fetching descriptions, screenshots, and trailers from Steam's public appdetails endpoint into a normalized cached shape. Results are cached locally for 14 days under app data, exposed through the new `fetch_store_metadata` Tauri command, and gated behind a default-on `fetch_store_metadata` setting.
- **Non-installed Games visibility toggle** - Library settings now include a toggle for showing owned-but-not-installed Steam games in the Games tab. Fresh settings hide those entries until a Steam account has connected once, then enable them by default; when hidden, the Games grid/source tabs and Right-Stick toolbar focus operate on installed games only while keeping the sticky sort control available.

### Changed
- **Background animations pause when LiftOff is unfocused** - while the window is blurred or a launch is in progress, JS-driven background effects (Webcore bouncing logo, Cyberpunk ascii-rain) stop their animation loops and all theme CSS background animations pause via a new `[data-focus="blurred"]` rule, so the GPU is not rendering frames no one is watching. Everything resumes immediately on refocus. The Cyberpunk rain now skips its per-frame canvas work entirely when frozen rather than redrawing a static frame each tick.

### Fixed
- **Game Details reveal focus and collapse** - pressing down from Play to reveal the Game Details controls now lands focus on the first controls-row item (first media tile or first action) instead of staying on the Play button, and pressing up from that first row reliably collapses back to the showcase view. Previously the reveal kept focus on Play in store-content Details mode, which also broke the up-to-collapse gesture because it only triggered when focus was past Play.
- **Game Details store media follow-up** - trailers now use HTTPS-normalized media URLs or Steam's current HLS/DASH manifest fields and play inside the fullscreen overlay, old cached trailer entries without playable URLs are refreshed through a store-metadata cache schema bump, trailers and screenshots share one numbered gamepad carousel, media-row left/right navigation can no longer land on the header Play button as an invisible item, the Details / Manage tabs stay hidden in the collapsed showcase but visible after reveal without shortening the content pane, and art pickers launched from Details return to the same Details modal on B/cancel instead of dropping back to the grid.

## [2.0.0-alpha-5] - Alpha 5

### Added
- **Steam download-size estimates** - not-installed Steam games now read the local Steam `appcache/appinfo.vdf` cache to estimate download/install size in Details without network calls, new dependencies, or Steam credentials. The parser is std-only, caches by `appinfo.vdf` modified time, sums public Windows depot `manifests.public.size` values while skipping DLC depots, and fails closed by hiding the size row if Steam's cache is missing or the format changes.
- **Background art backfill for uninstalled Steam games** - owned-but-not-installed game tiles now trickle through the existing art lookup path after startup, prioritizing the current Games view first and reusing the same cached grid/hero assets that Details already loads without adding backend work, settings, dependencies, or new strings.
- **Cloud Games kiosk launch** - cloud-source games now try to launch through the Windows default Chromium browser as a true kiosk window sized to the primary display, giving LiftOff a tracked browser PID for force-close handling. Unsupported browsers, missing browser registry data, or spawn failures fall back to the existing normal URL launch path, and generic non-cloud `https://` bookmarks continue to open with normal browser chrome.
- **Cloud Games picker and catalog refresh** - the Games Library Actions menu now includes "Add Cloud Game", opening a searchable, gamepad-navigable picker that renders its bundled `xcloudGames.json` seed immediately and refreshes a validated GitHub-hosted cache once per day.
